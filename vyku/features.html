FEATURES

功能说明

下面六项能力都已经在 Windows 与 Android 版本里实现。每一项后面都写了它不做什么，方便你判断是否合用。

三个数字

3

大类资产：实体、数字与文件，共用一套字段。

0

次云端上传：数据库、附件与使用数据都不离开设备。

1

个本地数据库文件，备份与恢复都以它为中心。

六项能力与它们的边界

资产管理

设备、账号、订阅、域名、服务器、证件和文件都能建条目，字段随类型切换，列表与搜索共用同一套数据。

边界：不做资产之间的依赖图，也不做批量导入图片。

附件管理

拍照、选图或选文件后，附件写入应用私有目录；入库前后各校验一次 SHA-256，失败时清理不完整文件。

边界：附件只看不编辑，不提供在线协作。

到期提醒

保修、域名和订阅可以设到期日，首页按已过期、即将到期和待处理分组；Android 上权限恢复后会重新调度。

边界：只做本机通知，不发短信或邮件。

本地搜索

搜索直接查询本机数据库，名称、备注和分类都能匹配，断网时结果不变。

边界：不做全文检索索引，也不检索附件内容。

加密备份与恢复

AES-256-GCM 加密的单文件备份，包含数据库、附件清单与校验值；恢复前验证，失败时安全回滚。

边界：备份需要你自己保管，没有云端副本。

导入导出与版本检查

CSV 与 JSON 用于明文交换；附件健康检查能发现缺失、哈希异常和孤儿文件；版本检查只访问公开接口。

边界：导入导出不含附件二进制，也不做跨设备同步。

三类资产怎么分

类型示例说明
实体资产手机、电脑、NAS、相机、家电有保修期和存放位置，适合记录购买与维修信息。
数字资产账号、订阅服务、域名、VPS / 服务器有续费周期和绑定邮箱，适合设置到期提醒。
文件资产证件、合同、发票、保修单、保险以附件为主体，适合记录编号与有效期。

一次完整的使用流程

  1. 01

    建立资产

    选类型、填名称与关键日期，其余字段按需补充。

  2. 02

    补上附件

    拍照或选文件，系统校验后写入私有目录。

  3. 03

    设置提醒

    填到期日，首页按紧急程度自动分组。

  4. 04

    定期备份

    导出加密备份包并另存，换设备时用它恢复。

能力边界

这一版不提供的

归屿没有账号，也没有云同步和网页端数据管理。它不会替你保管数据，数据始终在你的设备与你自己保存的备份里。

  • 没有在线预览与浏览器访问：附件只在客户端内查看。
  • 没有多设备同步：跨设备迁移请使用加密备份包。
  • 没有价格与订阅：这一版不涉及购买、会员或增值服务。
