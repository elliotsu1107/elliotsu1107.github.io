使用說明

從安裝到第一次備份。目前沒有公開建置，安裝步驟在發布後適用；資料位置、備份與限制說明現在就可以對照。

安裝

Windows 便攜版：解壓縮發布包到任意目錄，直接執行 vyku.exe。便攜包內帶 portable.flag，資料寫在程式目錄下的 data 裡，整個資料夾可以一起搬走。

Android：下載發布的安裝檔與同名校驗檔，先核對 SHA-256 再安裝。安裝時只暫時允許目前瀏覽器或檔案管理器「安裝未知應用程式」，完成後恢復禁止安裝設定。

最低系統版本：Android 為 Android 7.0（API 24）。該值取自 dist/V0.18.0-A-android/ 內 debug 建置的清單（aapt2 dump badging 輸出 minSdkVersion:'24'），與 android/app/build.gradle.kts:52 的 minSdk = flutter.minSdkVersion（Flutter 預設 24）一致。

Windows 方面，專案建置設定沒有宣告最低 Windows 版本（windows/CMakeLists.txt 與 windows/runner 均無版本斷言），因此本站不寫具體版本號，避免給出未經建置設定支援的承諾。

本站為預覽版本

目前不提供公開建置。上面的安裝步驟描述發布後的流程，現在沒有可下載的安裝檔。

首次使用

  1. 啟動後先看到空清單。點新增，選擇實體、數位或檔案類資產。
  2. 填名稱和類型必填欄位；有到期日的資產順手填上日期。
  3. 需要留憑證的資產，加入拍照或檔案附件，確認校驗通過。
  4. 開啟設定，確認主題、語言與資料目錄，記下資料位置。
  5. 做一次加密備份並另存到裝置之外，作為第一條還原基線。

備份與還原

  1. 在設定裡匯出加密備份，得到一個單一檔案包，副檔名為 .vbk。
  2. 把備份包另存到裝置之外，並按日期命名，保留最近幾份。
  3. 還原前選擇備份包，應用程式會先驗證資料庫與附件清單和校驗值。
  4. 驗證通過才寫入；失敗時回滾到還原前的狀態，原資料不會被破壞。

便攜版與安裝版之間移轉，也走同一條路徑：匯出加密備份，在另一台裝置還原。

附件

拍照、選圖或選檔案都可以。附件寫入應用程式私有目錄，寫入前後各校驗一次 SHA-256，不一致就清理並回報錯誤。

健康檢查會列出缺失檔案、雜湊異常和孤兒檔案，方便你在還原前確認備份包完整。

提醒

資產可以設到期日，首頁按已過期、即將到期和待處理分組；提醒可以跳回對應資產。

Android 上第一次建立提醒時按需請求通知權限，權限恢復後會重新排程未到期提醒。

平台與限制

先確認這幾條

歸嶼只在 Windows 與 Android 上建置和驗收；iOS 與 macOS 暫停。它沒有帳號，也沒有雲端同步，資料與備份都需要你自己保管。

  • iOS 與 macOS 暫停，沒有工程、安裝檔與驗收計畫。
  • 沒有帳號、登入與雲端同步，也沒有網頁端資料管理。
  • 附件只在應用程式內檢視，不提供線上預覽與瀏覽器開啟。
  • 備份沒有雲端副本；遺失備份包等同於遺失資料，請異地另存。
