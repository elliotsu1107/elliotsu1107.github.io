LOCAL-FIRST · FAMILY ASSETS

家庭資產，安放在你自己的裝置上

歸嶼把裝置、帳號、訂閱、證件和檔案收進一處，為它們附上附件、到期提醒和加密備份。資料只在本機，沒有帳號，也沒有雲端上傳。

三個設計取捨

本機優先

資料庫、附件和備份都留在你的裝置上。斷網時，資產、提醒和搜尋照常運作，功能不因網路而降級。

統一歸處

實體資產、數位帳號和檔案資產共用一套欄位與附件，續約日期和保固期不再散落在備忘錄裡。

到期提醒

訂閱、網域和保固到期前進入提醒清單，點開即可回到對應資產，處理後可以標記完成。

三類資產，一套欄位

類型範例常用欄位
實體資產手機、電腦、NAS、相機、家電購買日期、保固期、存放位置
數位資產帳號、訂閱服務、網域、VPS / 伺服器續約日期、綁定信箱、到期提醒
檔案資產證件、合約、發票、保固單、保險證件號碼、有效期限、附件

資料邊界

歸嶼沒有帳號系統，也沒有雲端同步。第一次啟動時，它只在你指定的目錄裡建立一個 SQLite 資料庫和一個附件目錄。

備份是 AES-256-GCM 加密的單一檔案包，包含資料庫、附件清單、大小和 SHA-256 校驗值；還原前先驗證，失敗時自動回滾。

唯一會連網的動作是版本檢查：只存取公開的 GitHub latest release 介面，不上傳裝置、資產或使用資料。

項目實際行為
儲存位置本機資料目錄，見使用說明
備份格式schema 3 加密單一檔案，Windows 與 Android 通用
上傳行為不上傳資料庫、附件或使用資料
網路請求僅版本檢查存取公開介面

六項已經實現的能力

  • 資產管理

    新增、編輯、刪除與分類，欄位隨資產類型切換。

  • 附件管理

    拍照或選擇檔案，寫入前後校驗 SHA-256，失敗時清理殘留。

  • 到期提醒

    保固、網域與訂閱到期提醒，Android 上支援通知權限恢復。

  • 本機搜尋

    在本機資料庫中尋找資產，不經過網路。

  • 加密備份

    AES-256-GCM 備份，還原前驗證，失敗時回滾。

  • 匯入匯出

    CSV / JSON 明文交換，以及公開穩定版本的版本檢查。

三種語言

介面提供簡體中文、繁體中文和 English，切換後重新啟動仍然保留。

說明、更新日誌和常見問題在三種語言下結構一致，術語與版本號互相對得上。

兩個平台

歸嶼目前在 Windows 與 Android 上建置和驗收。iOS 與 macOS 暫停，不提供工程與安裝檔。

兩個平台共用 schema 3 加密備份，可以靠加密備份包在裝置之間移轉資料。
