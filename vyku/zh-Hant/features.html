FEATURES

功能說明

下面六項能力都已經在 Windows 與 Android 版本裡實現。每一項後面都寫了它不做什麼，方便你判斷是否合用。

三個數字

3

大類資產：實體、數位與檔案，共用一套欄位。

0

次雲端上傳：資料庫、附件與使用資料都不離開裝置。

1

個本機資料庫檔案，備份與還原都以它為中心。

六項能力與它們的邊界

資產管理

裝置、帳號、訂閱、網域、伺服器、證件和檔案都能建條目，欄位隨類型切換，清單與搜尋共用同一套資料。

邊界：不做資產之間的相依圖，也不做批次匯入圖片。

附件管理

拍照、選圖或選檔案後，附件寫入應用程式私有目錄；寫入前後各校驗一次 SHA-256，失敗時清理不完整檔案。

邊界：附件只看不編輯，不提供線上協作。

到期提醒

保固、網域和訂閱可以設到期日，首頁按已過期、即將到期和待處理分組；Android 上權限恢復後會重新排程。

邊界：只做本機通知，不發簡訊或電子郵件。

本機搜尋

搜尋直接查詢本機資料庫，名稱、備註和分類都能比對，斷網時結果不變。

邊界：不做全文檢索索引，也不檢索附件內容。

加密備份與還原

AES-256-GCM 加密的單一檔案備份，包含資料庫、附件清單與校驗值；還原前驗證，失敗時安全回滾。

邊界：備份需要你自己保管，沒有雲端副本。

匯入匯出與版本檢查

CSV 與 JSON 用於明文交換；附件健康檢查能找到缺失、雜湊異常和孤兒檔案；版本檢查只存取公開介面。

邊界：匯入匯出不含附件二進位，也不做跨裝置同步。

三類資產怎麼分

類型範例說明
實體資產手機、電腦、NAS、相機、家電有保固期和存放位置，適合記錄購買與維修資訊。
數位資產帳號、訂閱服務、網域、VPS / 伺服器有續約週期和綁定信箱，適合設定到期提醒。
檔案資產證件、合約、發票、保固單、保險以附件為主體，適合記錄編號與有效期限。

一次完整的使用流程

  1. 01

    建立資產

    選類型、填名稱與關鍵日期，其餘欄位按需補充。

  2. 02

    補上附件

    拍照或選檔案，系統校驗後寫入私有目錄。

  3. 03

    設定提醒

    填到期日，首頁按緊急程度自動分組。

  4. 04

    定期備份

    匯出加密備份包並另存，換裝置時用它還原。

能力邊界

這一版不提供的

歸嶼沒有帳號，也沒有雲端同步和網頁端資料管理。它不會替你保管資料，資料始終在你的裝置與你自己保存的備份裡。

  • 沒有線上預覽與瀏覽器存取：附件只在應用程式內檢視。
  • 沒有多裝置同步：跨裝置移轉請使用加密備份包。
  • 沒有價格與訂閱：這一版不涉及購買、會員或加值服務。
