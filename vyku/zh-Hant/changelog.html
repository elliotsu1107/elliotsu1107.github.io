CHANGELOG

更新日誌

這裡只列已發布的版本，條目與倉庫 CHANGELOG 對應。

已發布版本

0.18.12026-11-07

  • 新增「開放原始碼授權」頁：設定 → 關於現列出應用內全部第三方元件（Flutter 框架與外掛）的 BSD / MIT / Apache 授權聲明。
  • 官方站點上線：elliotsu1107.github.io/vyku，下載頁顯示真實版本、檔案大小、SHA-256 與下載連結。
  • 修復按鈕繼承正文連結底線、行內程式碼退回瀏覽器預設等寬、強調字重過粗三處可見缺陷。
  • 深色主題下列印不再出現淺色文字印在白紙上。
  • 發版改為 GitHub Actions 自動建置：推送 tag 即自動建置雙平台並發布 Release。

0.18.02026-10-26

  • 完整遷移到 Clay 視覺體系：暖紙畫布、陶土強調、襯線標題與髮絲線分層，涵蓋 Windows 與 Android。
  • 三處前景色校準，逐對通過 WCAG AA 對比度；品牌陶土仍作為每屏唯一的強調色保留。
  • 新增靜態官網：三語共 18 頁，與用戶端共用同一套設計代幣，支援列印，全站零外部請求。
  • 修復 CSV 匯入缺陷，並增加表頭校驗，避免匯出的檔案被靜默重新匯入成亂碼。

0.14.12026-07-20

  • 限制備份檔案大小、ZIP 項目數、宣告解壓縮總量與壓縮率，降低異常備份導致記憶體耗盡的風險。
  • Android 正式發布：表單依欄位類型提供數字、日期、下拉、開關與多行控制項，並定位第一個錯誤。
  • 附件支援拍照、選圖與選檔案，寫入前後校驗 SHA-256，失敗時清理不完整檔案。
  • Windows 與 Android 統一 schema 3 加密備份，還原前驗證資料庫與附件，失敗時安全回滾。
  • 設定頁開放 Android 資料工具，並加入 24 小時自動更新檢查與手動檢查。

0.13.02026-07-15

  • Android MVP：新增平台工程與資產、提醒、設定三入口導覽。
  • 完成資產新增、檢視、編輯、刪除、搜尋篩選與提醒關聯資產跳轉。
  • 支援圖片應用程式內預覽，PDF 與文件交由 Android 系統應用程式開啟。
  • 資料儲存在應用程式私有目錄，關閉 Android Auto Backup。
  • 補齊三語，並通過 Android 斷網冷啟動驗收。

0.12.02026-07-05

  • 多端 UI/UX 基線：統一頁面基礎留白、卡片與狀態元件用法。
  • 統一首頁、搜尋、資產詳情、建立、編輯、提醒與設定的核心任務流骨架。
  • 資產表單加入必填校驗，錯誤靠近欄位展示，未儲存修改離開前二次確認。
  • 首頁提醒入口區分已過期、即將到期與待處理，並可跳轉關聯資產。
  • 設定頁按語言與顯示、資料與備份、匯入匯出、版本與關於分組。
