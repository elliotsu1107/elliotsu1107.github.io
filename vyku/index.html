LOCAL-FIRST · FAMILY ASSETS

家庭资产，安放在你自己的设备上

归屿把设备、账号、订阅、证件和文件收进一处，为它们附上附件、到期提醒和加密备份。数据只在本机，没有账号，也没有云端上传。

三个设计取舍

本地优先

数据库、附件和备份都留在你的设备上。断网时，资产、提醒和搜索照常工作，功能不因网络降级。

统一归处

实体资产、数字账号和文件资产共用一套字段与附件，续费日期和保修期不再散落在备忘录里。

到期提醒

订阅、域名和保修到期前进入提醒列表，点开即可回到对应资产，处理后可以标记完成。

三类资产，一套字段

类型示例常用字段
实体资产手机、电脑、NAS、相机、家电购买日期、保修期、存放位置
数字资产账号、订阅服务、域名、VPS / 服务器续费日期、绑定邮箱、到期提醒
文件资产证件、合同、发票、保修单、保险证件号码、有效期、附件

数据边界

归屿没有账号系统，也没有云同步。第一次启动时，它只在你指定的目录里创建一个 SQLite 数据库和一个附件目录。

备份是 AES-256-GCM 加密的单文件包，包含数据库、附件清单、大小和 SHA-256 校验值；恢复前先验证，失败时自动回滚。

唯一会联网的动作是版本检查：只访问公开的 GitHub latest release 接口，不上传设备、资产或使用数据。

项目实际行为
存储位置本机数据目录，见使用文档
备份格式schema 3 加密单文件，Windows 与 Android 通用
上传行为不上传数据库、附件或使用数据
网络请求仅版本检查访问公开接口

六项已经实现的能力

  • 资产管理

    新增、编辑、删除与分类，字段随资产类型切换。

  • 附件管理

    拍照或选择文件，入库前后校验 SHA-256，失败时清理残留。

  • 到期提醒

    保修、域名与订阅到期提醒，Android 上支持通知权限恢复。

  • 本地搜索

    在本机数据库中查找资产，不经过网络。

  • 加密备份

    AES-256-GCM 备份，恢复前验证，失败时回滚。

  • 导入导出

    CSV / JSON 明文交换，以及公开稳定版本的版本检查。

三种语言

界面提供简体中文、繁體中文和 English，切换后重启仍然保留。

文档、更新日志和常见问题在三种语言下结构一致，术语与版本号互相对得上。

两个平台

归屿目前在 Windows 与 Android 上构建和验收。iOS 与 macOS 暂停，不提供工程与安装包。

两个平台共用 schema 3 加密备份，可以按加密备份包在设备之间迁移数据。
