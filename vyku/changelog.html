CHANGELOG

更新日志

这里只列已发布的版本，条目与仓库 CHANGELOG 对应。

已发布版本

0.18.12026-11-07

  • 新增「开源许可」页：设置 → 关于现列出应用内全部第三方组件（Flutter 框架与插件）的 BSD / MIT / Apache 许可声明。
  • 官方站点上线：elliotsu1107.github.io/vyku，下载页显示真实版本、文件大小、SHA-256 与下载链接。
  • 修复按钮继承正文链接下划线、内联代码退回浏览器默认等宽、强调字重过粗三处可见缺陷。
  • 深色主题下打印不再出现浅色文字印在白纸上。
  • 发版改为 GitHub Actions 自动构建：推送 tag 即自动构建双平台并发布 Release。

0.18.02026-10-26

  • 完整迁移到 Clay 视觉体系：暖纸画布、陶土强调、衬线标题与发丝线分层，覆盖 Windows 与 Android。
  • 三处前景色校准，逐对通过 WCAG AA 对比度；品牌陶土仍作为每屏唯一的强调色保留。
  • 新增静态官网：三语共 18 页，与客户端共用同一套设计令牌，支持打印，全站零外部请求。
  • 修复 CSV 导入缺陷，并增加表头校验，避免导出的文件被静默重新导入成乱码。

0.14.12026-07-20

  • 限制备份文件大小、ZIP 条目数、声明解压总量与压缩率，降低异常备份导致内存耗尽的风险。
  • Android 正式发布：表单按字段类型提供数字、日期、下拉、开关与多行控件，并定位首个错误。
  • 附件支持拍照、选图与选文件，入库前后校验 SHA-256，失败时清理不完整文件。
  • Windows 与 Android 统一 schema 3 加密备份，恢复前验证数据库与附件，失败时安全回滚。
  • 设置页开放 Android 数据工具，并加入 24 小时自动更新检查与手动检查。

0.13.02026-07-15

  • Android MVP：新增平台工程与资产、提醒、设置三入口导航。
  • 完成资产新增、查看、编辑、删除、搜索筛选与提醒关联资产跳转。
  • 支持图片应用内预览，PDF 与文档交给 Android 系统应用打开。
  • 数据保存在应用私有目录，关闭 Android Auto Backup。
  • 补齐三语，并通过 Android 断网冷启动验收。

0.12.02026-07-05

  • 多端 UI/UX 基线：统一页面基础留白、卡片与状态组件用法。
  • 统一首页、搜索、资产详情、创建、编辑、提醒与设置的核心任务流骨架。
  • 资产表单增加必填校验，错误靠近字段展示，未保存修改离开前二次确认。
  • 首页提醒入口区分已过期、即将到期与待处理，并可跳转关联资产。
  • 设置页按语言与显示、数据与备份、导入导出、版本与关于分组。
