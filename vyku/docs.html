安装

Windows 便携版：解压发布包到任意目录，直接运行 vyku.exe。便携包内带 portable.flag，数据写在程序目录下的 data 里，整个文件夹可以整体搬走。

Android：下载发布的安装包与同名校验文件，先核对 SHA-256 再安装。安装时只临时允许当前浏览器或文件管理器「安装未知应用」，装完恢复禁止安装设置。

最低系统版本：Android 为 Android 7.0（API 24）。该值取自 dist/V0.18.0-A-android/ 内 debug 构建的清单（aapt2 dump badging 输出 minSdkVersion:'24'），与 android/app/build.gradle.kts:52 的 minSdk = flutter.minSdkVersion（Flutter 默认 24）一致。

Windows 侧，项目构建配置没有声明最低 Windows 版本（windows/CMakeLists.txt 与 windows/runner 均无版本断言），因此本站不写具体版本号，避免给出未经构建配置支持的承诺。

本站为预览版本

当前不提供公开构建。上面的安装步骤描述发布后的流程，现在没有可下载的安装包。

首次使用

  1. 启动后先看到空列表。点新增，选择实体、数字或文件类资产。
  2. 填名称和类型必填项；有到期日的资产顺手填上日期。
  3. 需要留凭证的资产，添加拍照或文件附件，确认校验通过。
  4. 打开设置，确认主题、语言与数据目录，记下数据位置。
  5. 做一次加密备份并另存到设备之外，作为第一条恢复基线。

数据位置

形态位置说明
便携版程序目录下的 data数据跟随文件夹移动，适合放在移动硬盘。
安装版系统应用文档目录Windows 通常为「文档」目录，实际路径以设置页为准。
数据库vyku.sqlite资产、附件索引与提醒都在这个文件里。
附件vault/assets/原始文件按内容寻址存放，不要在外部改名。
 
<程序目录>/data
vyku.sqlite
vault/assets/

备份与恢复

  1. 在设置里导出加密备份，得到一个单文件包，扩展名为 .vbk。
  2. 把备份包另存到设备之外，并按日期命名，保留最近几份。
  3. 恢复前选择备份包，应用会先验证数据库与附件清单和校验值。
  4. 验证通过才写入；失败时回滚到恢复前的状态，原数据不会被破坏。

便携版与安装版之间迁移，也走同一条路径：导出加密备份，在另一台设备恢复。

附件

拍照、选图或选文件都可以。附件写入应用私有目录，入库前后各校验一次 SHA-256，不一致就清理并报错。

健康检查会列出缺失文件、哈希异常和孤儿文件，方便你在恢复前确认备份包完整。

提醒

资产可以设到期日，首页按已过期、即将到期和待处理分组；提醒可以跳回对应资产。

Android 上首次创建提醒时按需请求通知权限，权限恢复后会重新调度未到期提醒。

平台与限制

先确认这几条

归屿只在 Windows 与 Android 上构建和验收；iOS 与 macOS 暂停。它没有账号，也没有云同步，数据与备份都需要你自己保管。

  • iOS 与 macOS 暂停，没有工程、安装包与验收计划。
  • 没有账号、登录与云同步，也没有网页端数据管理。
  • 附件只在客户端内查看，不提供在线预览与浏览器打开。
  • 备份没有云端副本；丢失备份包等同于丢失数据，请异地另存。
