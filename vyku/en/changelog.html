CHANGELOG

Changelog

Only released versions appear here, matching the CHANGELOG in the repository.

Released versions

0.18.12026-11-07

  • Open-source licences page: Settings → About now lists the BSD / MIT / Apache notices for every bundled third-party component.
  • The web site is live at elliotsu1107.github.io/vyku, with real version, file sizes, SHA-256 digests and download links on the download page.
  • Buttons no longer inherit the body-link underline; inline code now uses the monospace token; emphasis settles at weight 600.
  • Printing from the dark theme no longer produces light text on white paper.
  • Releases are now built and published automatically by GitHub Actions from a pushed tag.

0.18.02026-10-26

  • Full Clay visual migration: warm paper canvas, clay accent, serif headings and hairline layering across Windows and Android.
  • Three foreground calibrations so every text colour clears WCAG AA; the brand clay is preserved as the single accent.
  • Static web site: 18 pages in three languages, sharing the same design tokens, printable, with no external requests.
  • CSV import defect fixed, with header validation so an exported file cannot be silently re-imported as garbage.

0.14.12026-07-20

  • Cap the backup file size, ZIP entry count, declared uncompressed total and compression ratio, lowering the risk that an abnormal backup exhausts memory.
  • Android goes public: forms offer number, date, picker, switch and multi-line controls by field type, and focus the first error.
  • Attachments support camera capture, image picking and file picking, with SHA-256 verified before and after storage and partial files cleaned up on failure.
  • Windows and Android share the schema 3 encrypted backup; a restore verifies the database and attachments first and rolls back safely on failure.
  • Settings opens the Android data tools, and adds a 24-hour automatic update check alongside the manual one.

0.13.02026-07-15

  • Android MVP: a new platform project with navigation into assets, reminders and settings.
  • Asset create, view, edit and delete, plus search filtering and a jump from a reminder to its asset.
  • In-app image preview, while PDFs and documents open in Android system apps.
  • Data lives in the app's private directory, with Android Auto Backup turned off.
  • Three languages filled in, and an off-network cold start accepted on Android.

0.12.02026-07-05

  • A multi-surface UI/UX baseline: consistent page margins, and one way to use cards and status components.
  • One core task flow across home, search, asset detail, create, edit, reminders and settings.
  • Required-field validation on asset forms, errors shown beside the field, and a confirmation before leaving with unsaved changes.
  • The home reminder entry separates expired, due soon and pending, and jumps to the related asset.
  • Settings groups by language and display, data and backup, import and export, version and about.

Earlier versions

Earlier versions live in the CHANGELOG at the repository root. This site keeps summaries of the three released versions, lists no draft versions, and offers no subscriptions or filters.
