FAQ

Nine questions, ordered by platform, data, backup, attachments, reminders, exchange and limits. Every answer describes behaviour that already ships.

Questions and answers

Which platforms does Vyku support?

Windows and Android. Builds and acceptance for the two move together, and the backup format is shared. iOS and macOS are paused: no project, no installer, no acceptance plan and no timeline for resuming.

Is any data uploaded to the cloud?

No. Vyku has no account, no cloud sync and no cloud backup: the database, attachments and archives exist only on your device and wherever you store them yourself. The only network call is an update check against a public stable-release endpoint, and it never uploads devices, assets or usage data.

Where exactly does the data live?

The portable build writes to data beside the program; the installed build writes to the system documents folder. The database file is vyku.sqlite and attachments sit under vault/assets/. Do not mix database files between the two forms by hand — move data with the encrypted backup archive instead.

How do backup and restore work?

A backup exports one AES-256-GCM archive containing the database, the attachment manifest, sizes and SHA-256 values. A restore verifies first and only then writes; on failure it rolls back to the pre-restore state. One archive is at most 65 MB, with at most 256 ZIP entries, a declared uncompressed total of 64 MB and a single-entry ratio of at most 1000×.

Where do attachments go, and how do I view them?

Attachments are written to vault/assets/ in the app's private directory and stored by content. SHA-256 is checked before and after; a mismatch is cleaned up and reported. Viewing happens in the client: images have an in-app preview, and PDFs and documents open in a system app.

How are expiry reminders triggered?

Once an asset has an expiry date, the home screen groups it as expired, due soon or pending, and opening one returns to its asset. On Android the first reminder requests notification permission as needed, and pending reminders are rescheduled after permission is restored.

Can I import and export?

Yes. CSV and JSON carry plain data for your own checks or for a spreadsheet; the encrypted archive covers a full migration and restore. Import and export exclude attachment binaries, so attachments travel with the backup archive.

How do I know a new version exists?

Settings offers both paths: an automatic check every 24 hours, plus a manual check. The check only reads public stable-release information and uploads no device or usage data.

What are the known limits right now?

iOS and macOS are paused; there is no account or cloud sync and no web data management; attachments cannot be previewed online; backups have no cloud copy, so keep one off-site. V0.18.1 is public and available from the download page.

Still unresolved

For questions this FAQ does not cover, file an issue in the repository once a release exists. This site has no form, no support channel and no external links.
