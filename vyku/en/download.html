Release status

V0.18.1 was released on 2026-11-07; the Windows portable build and the Android package are available below.

Every file ships with a matching .sha256 file — verify it before installing.

Install and verify

  1. Download the installer and the .sha256 checksum file with the same name, and keep both in one folder.
  2. Verify SHA-256: on Windows run certutil -hashfile <file> SHA256; on Android compare it with a file manager or a checksum tool.
  3. On Windows, unzip and run; on Android, allow "install unknown apps" only for the install, then turn the setting back off.
  4. On first launch, make an encrypted backup immediately and store it off the device.

If verification fails, do not install: the download is incomplete or the file was replaced.
