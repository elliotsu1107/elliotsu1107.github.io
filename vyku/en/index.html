LOCAL-FIRST · FAMILY ASSETS

Your family's assets, kept on your own devices

Vyku gathers devices, accounts, subscriptions, documents and files in one place, with attachments, expiry reminders and encrypted backups. Everything stays on your machine: no account, no cloud upload.

Three design choices

Local-first

The database, attachments and backups stay on your device. Cut the network and assets, reminders and search keep working; nothing downgrades.

One home

Physical assets, digital accounts and document assets share one set of fields and attachments, so renewal dates and warranties stop living in scattered notes.

Expiry reminders

Subscriptions, domains and warranties enter the reminder list before they expire. Open one to jump back to its asset, then mark it done.

Three asset types, one set of fields

TypeExamplesTypical fields
Physical assetsPhones, computers, NAS, cameras, appliancesPurchase date, warranty, storage location
Digital assetsAccounts, subscriptions, domains, VPS / serversRenewal date, linked mailbox, expiry reminder
Document assetsCertificates, contracts, invoices, warranties, insuranceDocument number, valid until, attachments

Data boundary

Vyku has no account system and no cloud sync. On first launch it creates a SQLite database and an attachment folder inside the directory you choose.

Backups are single AES-256-GCM encrypted archives that contain the database, the attachment manifest, sizes and SHA-256 values. A restore verifies first and rolls back on failure.

The only network call is an update check: it reads the public GitHub latest release endpoint and never uploads devices, assets or usage data.

ItemActual behaviour
StorageLocal data directory, described in the docs
Backup formatEncrypted schema 3 single file, shared by Windows and Android
UploadsNo database, attachment or usage data leaves the device
Network callsOnly the update check reads a public endpoint

Six capabilities that already ship

  • Asset management

    Create, edit, delete and categorise; fields follow the asset type.

  • Attachments

    Take a photo or pick a file; SHA-256 is verified before and after storage.

  • Expiry reminders

    Warranties, domains and subscriptions; Android recovers notification permission.

  • Local search

    Queries the local database, so offline results are identical.

  • Encrypted backup

    AES-256-GCM archives, verified before restore and rolled back on failure.

  • Import and export

    CSV and JSON for plain data, plus update checks against public releases.

Three languages

The interface ships in Simplified Chinese, Traditional Chinese and English, and the choice survives a restart.

Documentation, changelog and FAQ keep the same structure in all three languages, with matching terms and version numbers.

Two platforms

Vyku is built and accepted on Windows and Android today. iOS and macOS are paused: no project, no installer and no acceptance plan.

Both platforms share the encrypted schema 3 backup, so data can move between devices as a backup archive.
