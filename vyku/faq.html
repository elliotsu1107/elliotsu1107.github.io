FAQ

常见问题

九个问题，按平台、数据、备份、附件、提醒、交换与限制排列。每条答案都只描述已经实现的行为。

问题与回答

归屿支持哪些平台？

Windows 与 Android。两个平台的构建与验收同步进行，备份格式互通。iOS 与 macOS 暂停：没有工程、安装包与验收计划，也没有恢复时间表。

数据会上传到云端吗？

不会。归屿没有账号，也没有云同步和云端备份：数据库、附件和备份包都只存在于你的设备与你自行保存的位置。唯一会联网的动作是版本检查，它只访问公开的稳定版本接口，不上传设备、资产或使用数据。

数据具体存放在哪里？

便携版写在程序目录下的 data；安装版写在系统应用文档目录。数据库文件是 vyku.sqlite，附件在 vault/assets/ 下。便携版和安装版不要手动混用数据库文件，迁移请走加密备份包。

备份和恢复是怎么做的？

备份导出为 AES-256-GCM 加密的单文件包，包含数据库、附件清单、大小与 SHA-256。恢复时先验证，验证通过才写入；失败会自动回滚到恢复前状态。单个备份文件最大 65 MB，ZIP 最多 256 个条目，声明解压总量最大 64 MB，单条压缩率不超过 1000 倍。

附件放在哪里，怎么查看？

附件写入应用私有目录的 vault/assets/，按内容寻址存放。入库前后各校验一次 SHA-256，不一致会清理并报错。查看发生在客户端内：图片有应用内预览，PDF 与文档交给系统应用打开。

到期提醒怎么触发？

给资产填写到期日后，首页按已过期、即将到期和待处理分组，点开可以回到对应资产。Android 首次创建提醒时按需请求通知权限，权限恢复后会重新调度未到期提醒。

可以导入导出吗？

可以。CSV 与 JSON 用于明文数据交换，适合自己核对或搬到表格里；加密备份包用于完整迁移与恢复。注意导入导出不包含附件二进制，附件要随备份包一起走。

怎么知道有没有新版本？

设置页提供自动与手动两条路径：每 24 小时自动检查一次，也可以手动检查。检查只访问公开的稳定版本信息，不上传任何设备或使用数据。

当前有哪些已知限制？

iOS 与 macOS 暂停；没有账号与云同步，也没有网页端数据管理；附件不能在线预览；备份没有云端副本，需要你自己异地保存。当前版本 V0.18.1 已公开，可从下载页获取。

仍未解决
